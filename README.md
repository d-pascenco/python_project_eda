# Анализ GitHub‑репозиториев с тегами AI/ML

Исследование посвящено сбору и разведочному анализу популярных GitHub‑репозиториев, отмеченных тегами **AI** и **ML**. Мы спарсили результаты глобального поиска GitHub, очистили данные, создали дополнительные признаки и построили визуализации, чтобы понять, что влияет на популярность open-source проектов.

## Состав репозитория
- `notebooks/github_ai_ml_analysis.ipynb` — основной ноутбук: парсинг, очистка, генерация признаков и визуализации. Внутри есть переключатель `USE_COLAB` для локального запуска и Google Colab.
- `raw_parsed_data/` — сырые выгрузки поиска GitHub по тегам AI и ML (`github_AI_repositories.csv`, `github_ML_repositories.csv`).
- `raw_concat_dataset/github_repositories.csv` — объединённый датасет до очистки.
- `new_index_dataset/github_repositories_new.csv` — итоговый датасет после очистки и обогащения (1685 строк, 24 признака).
- `требования_по_проекту.docx` — исходные требования по оформлению проекта.

## Быстрый старт
1. Установите Python 3.12.
2. Создайте виртуальное окружение (рекомендуется):
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Откройте ноутбук `notebooks/github_ai_ml_analysis.ipynb` и запустите его по ячейкам. Все описания из ноутбука вынесены в этот README, внутри остался только код.

### Настройка путей
В первой ячейке ноутбука переключите флаг `USE_COLAB` и задайте путь к данным:
- `True` — если запускаете в Google Colab (ноутбук смонтирует Google Drive и будет читать данные оттуда).
- `False` — для локального запуска. Пропишите путь к корню репозитория в `DATA_DIR`, например `Path("/home/user/python_project_mnad")`, чтобы ноутбук увидел папки `raw_parsed_data/`, `raw_concat_dataset/` и `new_index_dataset/`.

## Данные
- `raw_parsed_data/` — сырые выгрузки после парсинга GitHub.
- `raw_concat_dataset/` — объединённые наборы данных до очистки.
- `new_index_dataset/` — датасеты после очистки и создания новых признаков.

Если не хотите запускать парсинг, скачайте исходные CSV (`github_repositories_AI.csv`, `github_repositories_ML.csv`) из Google Drive: https://drive.google.com/drive/folders/1g35lFmY8D1aj2Smb53L9YXjkrm6WfI69 и положите их в `raw_parsed_data/`.

### Итоговый датасет
- 1685 наблюдений и 24 признака в `new_index_dataset/github_repositories_new.csv`.
- Ключевые признаки: активности (`Stars count`, `Forks count`, `Commits count`, `Pull requests count`, `Contributors count`), временные показатели (`Created`, `Last updated`), инженерные метрики (`Stars per contributor`, `Total changes`, `Community openness`, `Hype score`) и характеристики технологического стека (`Num languages`, `Has backend`, `Has frontend`, `Has infra`, `Has data`, `Stack breadth`, `languages_missing`).

## Как воспроизвести результаты
1. **Парсинг (опционально):** вызовите `run_parsing()` и укажите количество репозиториев по каждому тегу. Процесс может занять до двух часов. Если хотите пропустить парсинг, используйте готовые CSV в `raw_parsed_data/`.
2. **Очистка данных:** обработка пропусков в описаниях, удаление дубликатов, нормализация списка языков, фильтрация выбросов по метрикам активности.
3. **Обогащение:** расчёт временных метрик (возраст репозитория, давность обновления), индексов активности (stars/forks/commits per month), доли стеков технологий, флага пустых языков и т.д.
4. **EDA и визуализации:**
   - распределения звёзд, форков, коммитов и пул‑реквестов;
   - топ языков и стеков;
   - связи активности (например, звёзды vs. коммиты, звёзды vs. пул‑реквесты);
   - сравнение репозиториев по времени жизни и недавней активности.
5. **Экспорт:** промежуточный объединённый файл сохраняется как `raw_concat_dataset/github_repositories.csv`, финальный датасет — в `new_index_dataset/github_repositories_new.csv`.

## Основные выводы
- Популярность проектов зависит не только от количества звёзд, но и от регулярных коммитов и пул‑реквестов.
- Репозитории со свежими релизами и активными контрибьюторами чаще оказываются в топе поисковой выдачи.
- Языки Python и JavaScript доминируют среди AI/ML‑репозиториев, но комбинированный стек (несколько языков) встречается всё чаще.
